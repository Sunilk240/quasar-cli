## Key Capabilities

### 🤖 AI Agent

- Understands context from your codebase
- Plans and executes multi-step tasks
- Uses 27+ tools for file operations, search, web, and more

### 🔄 Multi-Provider

- Automatic failover between providers
- Rate limit rotation with multiple keys
- Local and cloud options

### 🔒 Safe Operations

- Automatic backups before file changes
- Blocks sensitive files (.env, SSH keys)
- Command suggestions (not direct execution)

### 🔌 Extensible

- MCP protocol support
- Custom lifecycle hooks
- Project-specific context via context.md
